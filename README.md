# 🛒 FlaskKart - E-Commerce Website

FlaskKart is a full-stack E-Commerce web application built using **Python Flask**, **SQLite**, **SQLAlchemy**, **HTML**, **CSS**, **Bootstrap**, and **Jinja2**. It allows users to browse products, manage their shopping cart, place orders, and provides an admin panel for product and order management.

---

## 🚀 Features

### 👤 User Features

- User Registration
- User Login & Logout
- Browse Products
- Product Details Page
- Product Search
- Category Filter
- Add to Cart
- Increase/Decrease Cart Quantity
- Remove Items from Cart
- Checkout Page
- Place Orders
- View Order History

---

### 🛍 Product Features

- Product Listing
- Product Details
- Product Image Upload
- Product Categories
- Product Search
- Responsive Product Cards

---

### 🔐 Admin Features

- Admin Dashboard
- Add New Products
- Edit Products
- Delete Products
- Upload Product Images
- View All Orders
- Update Order Status
